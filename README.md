# Budget Dashboard

## Tecnologias

- React 19
- TypeScript
- Vite
- Material UI
- React Query


## Arquitetura

A aplicação utiliza organização feature-first.


## Decisões

- React Query para gerenciamento de estado remoto.
- DTOs tipados para contrato da API.
- Axios centralizado.
- Proxy Vite para ambiente local.


## Executando

npm install

npm run dev
